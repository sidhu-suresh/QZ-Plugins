# quantzig-decks

v0.4.0 adds a mandatory clarifying round with tappable options and mandatory research for thin slides.

v0.3.0: one skill, qz-decks, replaces the separate qz-deck-formatter, qz-proposal and deck-visuals skills (all three are inside it).

Changes in this version: storyboard-first workflow with a hero visual and a unique layout per slide; self-explanatory density rule (90 to 160 words per content slide, takeaway line, no large empty areas); Grandview only; whole-point font sizes from 10pt with 10.5 allowed; brand colours only, with green, amber and red reserved for metric status; new formatting/scripts/deck_check.py; mandatory final slide-by-slide review table.
