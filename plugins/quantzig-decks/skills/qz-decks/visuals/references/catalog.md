# Visual library catalog

Library: `assets/visual-library.pptx` (330 slides, 10 x 5.625 in). Numbers are 1-based slide numbers for `visuals.py`.
Each category has a contact sheet in `assets/sheets/<id>.jpg` with slide numbers printed on every thumbnail: view it before choosing.
Columns: texts = editable text boxes, icons = swappable icon candidates, img = image slots. Counts are hints; run `inspect` for exact labels.
